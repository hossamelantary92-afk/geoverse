## Active Oceania card and header photo (v377)

The **active** Oceania image is an authentic aerial photograph of **Bora Bora, French Polynesia**, photographed by **Samuel Etienne** on 26 April 2010. Source: https://commons.wikimedia.org/wiki/File:BoraBora_SEtienne.jpg ; license: [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/). It is currently loaded directly from Wikimedia Commons at https://upload.wikimedia.org/wikipedia/commons/8/8d/BoraBora_SEtienne.jpg because the GitHub Actions photo-archiving workflow failed during this replacement. The existing `oceania.webp` listed above is the **previous archived local image**, not the currently selected card/header source. A future archive workflow should update that file and its credit before switching from the verified remote source.
